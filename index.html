    ⚰️ Causes of Death (أسباب الوفاة)

    الأسباب والاعتلالات المرضية الطبيعية (التي تُكتب في شهادات الوفاة داخل المستشفيات والمؤسسات الصحية في العراق دون الحاجة لتحويلها إلى الطب العدلي)

    1. أمراض الجهاز الدوري والقلبي

    • • توقف القلب التام أو المفاجئ (Cardiac Arrest / Asystole)
    • • احتشاء عضلة القلب الحاد (Acute Myocardial Infarction / جلطة القلب)
    • • قصور القلب الاحتقاني المزمن (Chronic Congestive Heart Failure)
    • • ارتفاع ضغط الدم الخبيث ومضاعفاته (Hypertensive Heart Disease)
    • • الجلطات والنزوف الدماغية التلقائية (Stroke / Intracerebral Hemorrhage)

    2. أمراض الجهاز التنفسي

    • • الالتهاب الرئوي الحاد أو القصباتي (Acute Pneumonia / Bronchopneumonia)
    • • فشل تنفسي حاد أو مزمن (Acute / Chronic Respiratory Failure)
    • • تفاقم الانسداد الرئوي المزمن (COPD Exacerbation)
    • • الانسداد الرئوي التجلطي (Pulmonary Thromboembolism)

    3. الأورام والأمراض السرطانية

    • • السرطان المنتشر والمتقدم (Disseminated Malignancy / Metastatic Cancer)
    • • الأورام الخبيثة العضوية (مثل: سرطان الرئة، القولون، الثدي، أو أورام الدماغ الخبيثة Glioblastoma)

    4. أمراض الجهاز الهضمي والكبد

    • • غيبوبة وفشل الكبد التام (Hepatic Failure / Hepatic Encephalopathy)
    • • تليف الكبد المزمن (Liver Cirrhosis)
    • • نزف الجهاز الهضمي العلوي الحاد (Acute GI Bleeding / دوالي المريء)
    • • التهاب البنكرياس الحاد (Acute Pancreatitis)

    5. أمراض الجهاز البولي والكلى

    • • الفشل الكلوي التام والمزمن (End-Stage Renal Disease / CRF)
    • • التسمم البولي / اليوريميا (Uremia)

    6. الأيض، الغدد الصماء والإنتان

    • • غيبوبة السكري (Diabetic Ketoacidosis / Hyperosmolar Coma)
    • • تعفن الدم الحاد والصدمة الإنتانية (Sepsis / Septic Shock)
    • • الفشل المتعدد للأعضاء (Multiple Organ Dysfunction Syndrome - MODS)

    7. أمراض الجهاز العصبي المركزي

    • • التهاب السحايا أو التهاب الدماغ الحاد (Acute Meningitis / Encephalitis)
    • • الوذمة الدماغية وارتفاع توتر القحف الحاد (Brain Edema / Raised ICP)
    • • مرض العصبون الحركي المتفاقم / التصلب الجانبي الضموري (ALS)
    • • مراحل الخرف المتقدمة وألزهايمر (Advanced Dementia / Alzheimer's Disease)
    • • نوبات الصرع المستمرة والمستعصية (Status Epilepticus)

    8. أمراض الدم واضطرابات التخثر

    • • فقر الدم الحاد والخطير (Severe Anemia / Aplastic Anemia)
    • • ابيضاض الدم الحاد والمتقدم (Acute Leukemia / Lymphoma)
    • • التخثر المنتشر داخل الأوعية (DIC)

    9. مضاعفات العمليات والتدخلات الطبية

    • • الصدمة الإنتانية أو الفشل القلبي/الرئوي اللاحق للعمليات الجراحية المبرمجة للمرضى (Post-operative Complications)

    10. الشيخوخة والوهن العام

    • • الوهن العام والشيخوخة المتقدمة مع توقف وظائف الأعضاء التدريجي (Advanced Senility / General Debility)

    11. الأمراض الاستقلابية والمناعية

    • • الفشل الغذائي الحاد وسوء التغذية الشديد المرتبط بالأمراض المزمنة (Cachexia / Severe Malnutrition)
    • • أمراض المناعة الذاتية المتقدمة (مثل: الذئبة الحمراء الجهازية SLE)
